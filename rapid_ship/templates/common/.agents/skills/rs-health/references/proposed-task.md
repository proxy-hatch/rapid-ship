# Proposed task

Each task fits one pull request within the 1,500 counted line diff cap. Give it:

- A title stating the outcome.
- The finding, with file:line or command output.
- The rung that carries the prevention.
- Acceptance criteria and a test plan.
- Tasks it waits on.

A Pattern finding cites that Pattern's Lessons. In a tracker, use one record per task and link the records it waits on.
